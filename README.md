# Сериализация двусвязного списка с произвольными ссылками (ListNode)

## 📌 Описание задачи

Необходимо реализовать сериализацию и десериализацию двусвязного списка следующего вида:

```cpp
struct ListNode {
    ListNode* prev = nullptr;
    ListNode* next = nullptr;
    ListNode* rand = nullptr;
    std::string data;
};

## 🧪 Описание unit-тестов

Тесты реализованы на базе GoogleTest и покрывают как корректные сценарии, так и ошибки.

### Основные группы тестов
1. Базовые сценарии пустой список один элемент список из нескольких элементов
2. Проверка связей корректность prev / next корректность rand self-reference (rand указывает на себя) перекрёстные ссылки
3. Данные UTF-8 строки строки со спецсимволами (;, пробелы) длинные строки (до 1000 байт)
4. Ошибки и edge-cases неверный magic в бинарном файле обрезанный файл некорректные индексы rand повреждённые данные

## 📦 Бинарный формат (layout)

Бинарный файл представляет собой массив байт в формате:

| Смещение | Поле  | Тип    | Описание         |
|----------|-------|--------|------------------|
| 0        | count | uint64 | количество узлов |

Далее повторяется `count` раз:

| Поле         | Тип    | Описание           |
|--------------|--------|--------------------|
| rand_index   | int64  | индекс узла или -1 |
| data_size    | uint16 | длина строки       |
| data         | bytes  | содержимое строки  |
